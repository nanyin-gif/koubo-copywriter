# 口播文案大师（koubo-copywriter-lite）

> 抖音 / 快手爆款真人口播文案生成 Skill —— 给个主题，直接出稿。

一个纯文字版的 AI Skill：输入主题，自动产出**可直接录制**的口播文案「五件套」——钩子 / 配音文案 / 视频标题 / 发布文案 / 话题。主打 **3 秒钩子、去 AI 味、时长自由**，自媒体新手也能 10 分钟上手。

---

## ✨ 核心亮点

| 亮点 | 说明 |
| --- | --- |
| 🪝 3 秒钩子 | 内置 8 类钩子套路：自问自答、反常识断言、场景代入、识人观察……挑一个就能开场 |
| 🎁 五件套交付 | 钩子 / 配音文案 / 视频标题 / 发布文案 / 话题，一次配齐，拿到就能录 |
| 🧹 去 AI 味 | 自带自检清单：禁词表 + 句式规则 + 人味技法，逐条打勾，念一遍不"像念课文" |
| ⏱️ 时长自由 | 20 / 30 / 60 / 90 / 120 秒语速换算表，时长随你定 |
| 🔁 双模式 | 从零创作（没灵感给个主题）+ 改编二创（有素材丢进去就变你的稿） |
| 📦 零门槛 | 纯 .md 文件，无需编程，任何支持 Skill 的 AI 环境都能用 |

## 🚀 安装

需要**支持 Skill 的 AI 环境**（Claude Code、Codex、OpenClaw 等主流 Agent 均可）。

**方式 A：导入文件夹**
1. 在支持"导入 Skill / 安装 Skill"的 AI 助手中，选择本仓库的 `koubo-copywriter-lite` 文件夹。
2. 按页面提示完成导入。

**方式 B：手动放入 skills 目录**
1. 把整个 `koubo-copywriter-lite` 文件夹复制到该平台的 skills 目录。
2. 重启 / 刷新 AI 助手。

安装完成后，在对话中直接说「用 $koubo-copywriter-lite 写一条口播文案」即可调用。

## 📝 使用

### 模式 A · 从零创作（没灵感）
直接说需求：平台 + 主题 + 时长（随你定）。

```
用 $koubo-copywriter-lite 写一条 30 秒、主题"成年人清醒"的抖音口播文案，交付五件套。
```

### 模式 B · 改编二创（有素材）
把文章 / 故事 / 金句 / 别人的文案丢给它，自动换开头、换视角、换场景，规避查重。

```
用 $koubo-copywriter-lite 把下面这段文字改成一条 1 分钟快手口播：
（粘贴原文）
```

### 每次交付的五件套
1. 【钩子】开场第一句 + 钩子类型说明
2. 【配音文案】可直接录制的口播正文
3. 【视频标题】第一句到问号为止，逗号即换行、最多两行
4. 【发布文案】2-3 句平台发布文案，含互动引导
5. 【关联话题】3-5 个话题标签

> 想挂自己的素材？把素材（自己写的 / 公版诗词 / 买过版权的资料）整理成 .txt 放进一个文件夹，把路径告诉 AI，它会先读取作灵感，成稿仍是原创表达。

## ❓ 常见问题

**Q：需要编程基础吗？**
A：不需要。纯文本 .md 文件，导入即用。

**Q：生成的文案能直接用吗？**
A：可以直接录制。发布前建议按 `references/deai-checklist.md` 过一遍自检，并核对平台最新审核规则。

**Q：素材库在哪里？**
A：本仓库不内置任何第三方版权素材。古诗词等公版内容可在 `references/` 中参考；其余素材建议使用自己合法拥有的内容。
