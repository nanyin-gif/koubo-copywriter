# 爆款口播结构库（抖音/快手）

> 依据：对两大平台高播放真人口播的观察 + 公开方法论（3秒法则、钩子公式、完播率逻辑、平台调性差异）。可用于持续校验和更新本库。

## 0. 先定"算法参数"
- 前3秒留存决定推流：开头必须在前2句话内给出"停下来的理由"。
- 抖音：语速快（约4字/秒），情绪共鸣+金句，关键指标：完播率、评论。
- 快手：语速稍慢（约3.6字/秒），真实+接地气+质朴，关键指标：完播、评论、转发。
- 每10-15秒一个信息点/情绪点；以60秒为例：1-2句可收藏金句 + 1个具体场景 + 1次情绪起伏，更长文案按比例增加信息点。

## 1. 开头钩子（前3秒，选1个）
1. 反常识断言：颠覆认知，制造"认知缺口"。「你越懂事，越没人疼。」
2. 直问戳心：用"你有没有发现/你有多久没……"把观众拉进话题。
3. 场景代入：具体到时间、地点、动作的细节开场。「凌晨一点，你刷到这条视频……」
4. 数字/清单预告：「记住这三句话，能少走十年弯路。」
5. 先抛金句：一句可收藏的话先行，后文展开。
6. 反向输出/揭秘：「我们都被'懂事'这两个字，骗了很多年。」
7. 共鸣陈述：「成年人的崩溃，往往就在一瞬间。」

坏开头（禁用）："大家好，今天给大家分享……""在这个快节奏的时代……"等慢热/套话开场。

## 2. 正文框架（选1个）
1. 观点-故事-升华：抛观点 → 讲一个具体的"我/你/身边人"的故事（带细节）→ 收回一句升华。
2. 正反对比：「以前以为……后来才明白……」两段对比 + 一句落点。
3. 三层递进：把一件事拆成三层讲，层层加深，第三层才是落点。
4. 排比破局：工整排比最多两段，第三句必须换成散句/短句，打破"AI工整感"。
5. 场景连拍：两三个短场景并列（不用连接词），最后一句总结。
6. 情绪弧线：平淡叙述 → 情绪爆发（最高点）→ 突然收敛（留白）。

## 3. 收尾（选1个）
1. 升华金句：整条收成一句可收藏的话；金句要"人话"，别太对仗。
2. 互动提问：「你也有过这种感觉吗？评论区聊聊。」
3. 行动暗示：「这条建议收藏，迷茫的时候翻出来看看。」
4. 留白：「剩下的，你自己品。」

## 4. 表达特征（真人口播的"语感"）
- 短句为主，多断句，允许半句话；单句尽量不超过20-25字。
- 多用口语词：其实、真的、说白了、你发现没、对吧。
- 少用书面连接词：然而、此外、综上所述、首先/其次/最后。
- 多用"你"，少用"我们大家"；讲自己的故事拉近距离。
- 具体细节大于抽象概念：不说"很辛苦"，说"凌晨两点还在回消息"。
- 金句密度：60秒1-2句，用大白话讲，不堆成语。

## 5. 平台差异速查
| 维度 | 抖音 | 快手 |
| --- | --- | --- |
| 气质 | 都市、清醒、利落、有态度 | 接地气、质朴、真诚、家常 |
| 开头 | 更"炸"：反常识/金句先行 | 更"近"：场景代入/掏心窝子 |
| 叙事 | 观点驱动 | 故事/事例驱动 |
| 用词 | 略书面一点也可以 | 大白话、方言味更吃香 |
| 禁忌 | 过度说教、假精致 | 端着、装、不接地气 |
